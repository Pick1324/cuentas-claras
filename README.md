# Cuentas Claras

App gratuita para ordenar las finanzas del hogar: presupuesto mensual, vencimientos, registro de gastos y un plan para salir de las deudas.

**Usala acá:** https://pick1324.github.io/cuentas-claras/

## Qué hace

- **Mes:** cuánto te queda para el resto del mes después de cuotas, gastos fijos y lo que ya gastaste. Lista de vencimientos para ir marcando como pagados.
- **Gastos:** anotás cada compra con su categoría.
- **Deudas:** cuotas que faltan, cuándo terminás y cuál conviene adelantar primero (la de mayor costo mensual).
- **Ajustes:** ingreso, deudas (también con cuotas distintas mes a mes, como el Plan V de la tarjeta), gastos fijos mensuales o bimestrales, respaldo y avisos.

## Privacidad

Tus datos se guardan **solo en tu celular** (en el navegador). No hay cuentas, servidores ni publicidad. Nada se sube a internet. Usá **Ajustes → Descargar respaldo** para guardar una copia.

## Cómo instalarla en Android

1. Abrí el enlace en **Chrome**.
2. Tocá el menú ⋮ → **Agregar a la pantalla principal** (o **Instalar app**).
3. Queda con su ícono y funciona sin internet.

## Avisos

Al abrir la app te avisa lo que vence en los próximos 3 días (activá las notificaciones en Ajustes). Para avisos con la app cerrada, usá recordatorios del calendario del celular.

## Para desarrolladores

Es una página estática (HTML, CSS y JavaScript sin dependencias) con service worker para funcionar sin conexión. Para publicar tu copia: hacé un fork y activá **Settings → Pages → Deploy from a branch → main / (root)**.
